The folder Aux_Material contains the Python scripts used to obtain the results presented in the manuscript. It must be placed within the KrakenOS directory for proper execution at the same leve of the Examples field. This package includes the following:

Scripts for the first-order analysis, third-order modeling, physically grounded merit function (PGMF) optimization, and RMS-based refinement.

A subfolder named Images that stores the figures generated by six of the seven provided scripts.

A utils directory that contains supporting classes and equations required for the execution of the main optimization and modeling routines.

The scripts rely on the following Python packages, we provide the links to the repository of some:

NumPy version 1.22.1

SciPy version 1.7.3

PyGAD version 3.0.1
(https://pygad.readthedocs.io/en/latest/#)

bees-algorithm version 1.0.2
(https://pypi.org/project/bees-algorithm/)

KrakenOS version 1.0.0.19
(https://github.com/Garchupiter/Kraken-Optical-Simulator)

matplotlib version 3.5.2

All scripts are modular and structured to reflect the design stages discussed in the manuscript.
